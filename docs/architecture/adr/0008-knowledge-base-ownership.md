# ADR-0008：知识库作为唯一内容授权边界

状态：Accepted；日期：2026-10-16。用户确认：按知识库隔离，旧库由管理员一次性指定所有者，原文件保留原位。

替代 [ADR-0007](0007-personal-wiki-authorization.md) 的个人 Wiki 目标。每个库登记 orgId/ownerUserId；库内原文、块、Wiki 和修订继承库权限，不建设文档/页面 ACL。作者与原上传者是审计/物理定位信息，不是最终权限条件。版本、删除、同库引用与内容完整性检查保留。

旧库无可靠创建者，不自动认领、不默认开放；管理员只看到待指派摘要，通过专用接口明确选择同组织有效用户。普通配置保存不能指派、转移或复活已删除库。新库由认证用户创建，服务端设置归属。管理员不是他人知识库的隐式读者。暂不支持转移与共享角色矩阵。

配置保存从全量覆盖改为仅更新当前用户名下的库，保留其他用户和未指派库。删除配置保留墓碑，防止复用 ID 指向旧数据。新本地库使用服务端托管目录；既有库的 provider/位置不可通过普通保存改绑。配置原子替换，首次写入前备份旧配置；不自动迁移 SQLite 或搬动原文件。

分步交付：WK-T09a 先建立归属登记、配置隔离、管理员指派和知识 API 的库级守卫；WK-T09b 再兼容原有个人 Wiki namespace 与原文件定位，去掉库内重复用户限制。过渡期不直接移除旧保护，不能声称已完成全链路库内继承或完整多租户安全。模型生成/UI 仍按原计划推进。

回滚不能运行旧的全量配置写入器覆盖新归属；保留兼容代码或停止服务，从备份恢复须停机评估期间新增数据。测试只用临时数据。当前实现/验证见 [Wiki 状态](../../sdd/features/knowledge-wiki/status.md)。

# 离线召回评测报告

状态：已实现，工程验证见status；版本：1；日期：2026-10-21。

## 需求 / 任务 / 测试追踪

KEV-01 → KEV-T01 → KEV-TEST-01：只输出报告，不参与查询、排序、配置更新或后台采样。第一阶段使用人工标注的冻结召回快照，不自动跑题库。不接统一Reranker、模型裁判、自动调参和评测平台。

## 架构与契约

contracts定义version=1的离线JSON；renderer独立懒加载面板与纯计算模块。没有新API、数据库、调度任务或网络调用。普通查询不执行评测，仅在用户点击时导出已有结果的id/title（不含正文、密钥）。文件不上传；关闭页面后报告不留存，可下载HTML长期查看。文件含问题和标题，用户自行保管。

输入：knowledgeBaseId、snapshot（人工填写资料版本/采集范围）、topK（1～20）、cases（1～100）。每题有唯一id、query、relevantGroups（null=未标注；[]=确认无答案；每个非空组包含可替代的命中id，原文与Wiki若表达同一证据放同组）、runs（1～5个一致命名的variant，各含有序hits[id/title]及可选elapsedMs）。同题各组ID不能重叠，重复样本/variant拒绝。variant必须在所有题出现。知识库不匹配拒绝。最大文件2MiB，全部标注后才生成报告。快照声明不代表系统验证资料版本一致；正文正确性/来源有效性须人工核对。

命中id：原文 `chunk:<id>`、Wiki `wiki:<pageId>`；未返回但应命中的ID也须加入标准组。相同证据组只计首次命中，重复结果不挤掉原始排名。每个有答案题输出Hit@K、Recall@K、MRR@K、有效结果占比（去重命中数/实际返回条数）、二值去重nDCG@K。按题宏平均；无答案题单列空返回率，不混入Recall/MRR分母。耗时只汇总显式提供的记录，显示计数与P95；不虚构未采集耗时。不输出自动优劣结论。

## UI / 状态

知识库→「召回验证」旁的「查看测试与报告」→折叠的「离线评测报告」。无需先查询，点击展开才加载计算和面板；提供导出当前快照、下载格式示例、选择标注文件并生成报告、下载HTML。空态说明流程，非法/超限/未标注显示可读错误且清除旧报告，文件读取期间禁用；卸载隔离迟到结果。折叠保留报告，离开页面需重新导入。报告内有汇总和逐题明细，明细默认折叠。HTML所有输入转义，无脚本/远端资源，CSP禁止连接。

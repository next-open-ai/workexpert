## 需求与契约

CB-01：平台身份统一为 WorkExpert，保留员工角色名称。默认员工、客户端/服务端员工提示、项目规划及Pi运行提示不再注入旧品牌。执行入口添加身份和能力真实性约束，旧对话自述不作为当前能力来源。

CB-02：员工mcpIds为空或缺失时不加载任何MCP；只有显式关联且启用、未探测失败的连接器可装配。客户端与服务端一致。指定owner时仅使用该用户偏好/连接目录，空或缺失不回退其他用户/全局配置；无owner的旧调用仅使用明确的全局配置，不扫描其他用户。新预置目录默认禁用；不删除或重写用户已有连接。原先依赖空列表自动加载的用户须明确勾选。

CB-03：能力介绍以本次实际提供的工具为准；技能说明不等于工具授权、工具存在不等于供应商可用，不声称所有能力免安装/无需环境。未加载MCP明确说明，不复述历史虚构能力。Pi提供实际工具名称清单；不做固定话术拦截或回答字符串替换。

CB-02执行边界：编排runner及旧/chat入口执行前根据已验证运行owner重新装配，忽略客户端及旧快照携带的连接器；缺少owner时不授权MCP。CB-R01覆盖旧列表替换、原请求不变及无owner拒绝。服务端明确关联是唯一授权来源。

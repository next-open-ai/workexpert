# Requirements

> 状态：已接受｜规格版本：0.1｜更新日期：2026-10-06

- `REL-01` 非对话工作区按需加载，体积门禁分别约束首屏代码、最大代码块、总代码和静态媒体。
- `REL-02` Headless 与 Gateway 离线冒烟自行托管隔离 API，执行后必须清理进程与数据。
- `REL-03` 浏览器回归覆盖首次管理员、登录会话、核心导航、设置与未配置模型空态。
- `REL-04` npm tarball 不包含 Python 缓存、测试编译物或 source map，且安装后的 `workexpert doctor` 可运行。
- `REL-05` 发布报告必须区分本机已验证、真实 Provider 未验证和异平台未验证，不得以构建代替安装验收。

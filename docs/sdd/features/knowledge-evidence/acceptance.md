# 检索验收说明

关联：KE-T04c / KE-A01～03；题集版本 synthetic-keyword-v1；日期 2026-10-16。

## 自动回归

运行 `pnpm knowledge:acceptance`。使用临时目录、真实 SQLite FTS5/LanceDB、桩 Embedding；结束清理本次临时数据，不读取用户知识库，不发送真实模型请求。源快照为测试构造，原文件归档另由 API/storage 回归验证。

固定题集位于 `packages/agent-core/src/test/knowledge-acceptance.test.ts`：8 篇原创模拟文档、10 道正例，涵盖中文、专名、编号、全半角、英文、表格和列表。文档内容不是企业实际制度；逐题输出预期文档、实际 Top3 和排名，汇总文档级 Hit@3、MRR@3。每题至少命中预期文档为功能门禁，结果和证据必须来自关键词一路。另验空查询、无匹配、同义表达未匹配、删除后不回流与其他文档不受影响。

同一命令包含已有混合召回、版本切换、降级、父块和删除竞争回归。模拟向量只用于机制验证，不能评估语义效果；10 道易匹配题即使全中也不代表真实业务召回率，不作性能或正式 Benchmark 基线。若要更换题意或期望文档，应升级题集版本，不能为了通过测试改写答案。

## 业务与桌面验收（需另行执行）

使用隔离验收知识库，导入用户提供的脱敏文档，先由业务人员标注至少 20 个问题对应的文档/段落，其中包含同义表达、近似编号、跨段上下文和不应回答的问题。记录语料版本、模型与参数、应用版本、每题 Top3、误召回、缺失证据和人工判定；不向未授权的模型服务传输材料。

| 场景 | 验收标准 |
| --- | --- |
| 文件/文本导入 | 显示处理中；只有发布成功才显示可检索；失败保留输入且不把归档当成功 |
| 普通搜索 | 命中原文正确，排序分不解释成置信度；新请求失败不保留旧结果 |
| 上下文 | 有父块才显示折叠，默认收起；展开不混入其他版本/已删除片段 |
| 定位 | 片段对应规范化文本偏移，不误称原文件页码 |
| 无匹配/模型不可用 | 空态或降级提示清晰；不要求用户选择数据库 |
| 文档删除 | 说明原文保留；再次搜索无该文档，其他文档仍正常 |
| 快速交互 | 连续搜索或切换知识库，旧请求不得覆盖新库结果 |
| 重启/安装态 | 重启后能检索；验证打包后 SQLite/FTS5/LanceDB 可用 |

`pnpm ui:core:regression` 只证明浏览器登录、导航和空态等基础路径，不覆盖上表完整旅程，也不代替 Electron 安装态验收。当前实际执行结果以 [status.md](status.md) 为准。

`pnpm ui:knowledge:regression` 构建前端并增加 KE-U01/U02 搜索专项：重复 Enter、编辑查询、切换知识库、返回同库、卸载、迟到成功/错误/完成状态、命中来源/降级/空态/本体说明和默认折叠上下文。使用真实浏览器与受控 API 响应，不运行真实知识入库；API dist 需预先构建，与现有 core UI harness 相同。此测试不覆盖真实原文、全文索引或安装态。

`pnpm ui:knowledge:lifecycle` 构建契约、storage、agent-core、API 和前端后执行 KE-E01～04：真实设置 API 预置隔离知识库，浏览器上传 Markdown/粘贴文本，真实归档、索引、检索、上下文、片段定位、失败重试、刷新与删除。只模拟 localhost Embedding 服务，不拦截知识接口；断言全文/向量命中元数据、版本证据摘要、原文下载保真、失败文档不进入 FTS、删除后不回流。测试会清理本次临时目录，不操作真实用户数据。需要已安装 Chrome/Chromium，或以 `WORKEXPERT_BROWSER_EXECUTABLE` 指定浏览器。

KE-E01～04 中 Markdown 经现有 UI 读为文本再提交。KE-E05～06 进一步上传程序生成的简单文本 PDF、中文段落 DOCX，核对归档原字节/文件名/摘要与正文关键词召回；损坏 DOCX 不调用向量、不发布。随后正常终止本次 API 子进程并以同一临时目录启动新进程，核对重启后有效内容仍可检索、删除/失败内容不回流、归档可读。只允许停止 harness 自己创建的进程，正常重启用例拒绝把超时强制终止算作正常停机。

这些是基础解析与持久性回归，不覆盖扫描/OCR、中文 PDF 字体、复杂布局或崩溃恢复。固定向量只验证链路，不评价语义质量或业务相关性；Electron 安装态、真实模型和脱敏业务材料仍需单独验收。中文 OR 查询可能命中其他文档共有词，删除验收按文档证据身份校验，不把任何非空结果误判成回流。

状态：已接受；规格版本：0.2；更新日期：2026-10-16。关联：[任务 WK-T08](tasks.md)、[UI](ui.md)。这是未来手册交付清单，不是已上线操作说明。

## 单一源与生成链路

权威用户手册为 [docs/guides/user-manual.md](../../../guides/user-manual.md)。实现并验收对应功能后修改其知识库章节，再运行 `pnpm manual:generate` 生成 `apps/renderer/src/generated/user-manual.json`；禁止手工只改生成 JSON 或新建另一份竞争手册。

## 必须新增的内容

1. Wiki 与原始资料区别：Wiki 是整理结果，不保证覆盖全部资料，不是独立原始证据。
2. 从知识库进入 Wiki，首次选择资料与生成模型，查看预算和数据发送范围。
3. 生成进度、部分完成、失败、取消和重启后手动恢复；“草稿生成完成”不等于发布。
4. 核对来源、修改草稿、比较版本、显式发布；冲突保留输入。
5. 目录/搜索/互链/返回导航、相关页与反向链接；搜索是词法，不承诺同义语义搜索。
6. 从章节引用定位原文；normalized-text 非 PDF 页码，原文件查看受独立权限控制。
7. 来源更新、删除、权限变化与待核对/不可访问提示；如何重新生成和发布。
8. 页面归档、历史恢复为草稿、原文归档保留说明；不宣称提供物理删除/GC。
9. 无模型仍可阅读搜索；首期不依赖本体、Neo4j、WeKnora 或 MediaWiki，不支持外部 Wiki 同步。

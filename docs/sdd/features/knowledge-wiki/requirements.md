## 非目标

本体建模、实体关系图谱、图谱可视化、Wiki 向量/RRF/精排、自动问答工具接线、跨知识库页面链接、外部站点发布、实时协同编辑、MediaWiki 双向同步、原文件 GC 均不在首期。章节保存用于导航/引用，不代表首期已有章节级 FTS。

## 数据及质量边界

仅 versioned 且可验证/可读取的有效证据可生成；legacy-unverified 明确提示先重新入库，不伪造版本。文档内指令视为不可信资料，不授权工具、外网或文件操作。自动摘要是派生观点，不作为第二份独立事实。模型未提供充分支持的陈述应进入待核对项；结构校验不代替事实审查。

首期完成定义为 WK-01～12 对应测试、可用 UI 和手册全部交付；模拟模型测试只能证明工程链路，真实业务质量与安装态单独记录，不偷换验收范围。

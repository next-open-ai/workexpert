# Wiki 有界分批生成（WK-T04b）

2026-10-21 WK-R18 → WK-T18 → WK-R18-T：[显式断点续跑](resumable-generation.md)替代下文“候选仅内存/不能续跑”的历史限制。旧任务仍只能重新生成，新任务按私有检查点恢复；不自动调用模型，实际验证见 status。

状态：实施中；规格版本：0.7；日期：2026-10-16。关联：[ADR-0006](../../../architecture/adr/0006-evidence-driven-wiki.md)、[状态](status.md)。本阶段替代 closure 中单批输入限制，不扩大权限范围。

## 范围与契约

WK-02/03/08/09/12 → WK-T04b → WK-G01b/G02b/A06。最多仍选 5 份资料；总计 400 个子块、192,000 个 UTF-16 字符、512,000 字符序列化快照。按文档和块原顺序划分最多 8 个调用批次，每批最多 100 块、48,000 字符、128,000 字符快照。不截断、不 TopK 抽样；单块无法装入或批次数超限时在模型调用前返回 413。小输入保持一次调用。

orchestrator 顺序调用各批，逐批持久化 processedChunks；全部成功后在 agent-core 纯函数中归组并保存草稿。单次调用超时仍为 120 秒，每批最多 8 页，任务最多 64 页；不增加自动重试/自动恢复，SDK 传输重试仍受单批取消/超时限制。批中失败或取消停止后续调用，未保存的中间候选只在内存中，不承诺断点续算；已保存草稿继续保留。processedChunks 仅表示已通过引用覆盖校验的块数，不代表已保存或语义正确。

主题归组仅作用于本次任务：标题精确相同且每批最多出现一次的候选可组合章节，保留原顺序、全部正文、摘要、别名和证据，不重写或裁决矛盾，不合并已有页面。遇到同批重名（可能歧义）或组合后超过页面契约容量则保留独立页面。链接重映射至归组后的稳定 ID，删除合并产生的自链接，章节区间与引用 ID 重建。此为同名内容汇集，不等于语义消歧或全库去重，发布前仍须核对。

任务 JSON schemaVersion=1 扩大 totalChunks/processedChunks 到 400、pageIds 到 64；无新增字段、表、数据库版本、服务或依赖。旧任务可读，新大任务不能交给旧的严格上限读写器；回退应关闭新生成入口，保留本版兼容读写器与数据，不降级数据库。界面仅增加已处理块数及自动分批说明，没有新设置或权限按钮。

## 验证计划

- WK-G01b：顺序分批、每块恰好一次、总量/单块/元数据超限、同名归组、歧义保留、容量回退、Unicode 位置、引用与链接重映射。
- WK-G02b：串行调用、逐批进度、失败/取消不继续调用、不保存不完整候选、幂等不重跑、旧任务兼容。
- WK-A06：真实 Fastify/SQLite/归档，多批生成到草稿/发布/检索；输入变化拒绝保存。仅模型适配 mock，不操作真实资料。
- 运行受影响包测试、类型检查、Wiki 浏览器既有闭环、并发专项、手册生成/回归和文档构建。实际结果仅在 status 登记；真实模型质量与安装态不在本次验收内。

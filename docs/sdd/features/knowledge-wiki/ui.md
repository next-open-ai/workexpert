## WK-T06d：多选和全部发布（0.10，2026-10-17）

左侧待发布草稿提供复选框、全选全部草稿、取消全选、发布所选和全部发布。全选/全部发布遍历全部目录分页；读取失败不提交部分列表。保留右侧预览，确认一次实际页数及已核对来源。逐页发布、展示进度和失败原因，成功不回滚，失败保留选择。选择冻结 generation/草稿修订，变化后必须刷新核对并重新选择，不暗中发布新版。批量期间禁用修改/切换/搜索，仍可预览；离开停止后续提交，在途请求可能完成，不提供后台续跑。

## WK-T06c：直接打开与页面章节树（0.9）

关联 WK-06/08/12，验收 WK-U05。知识库列表的本地库卡片增加“打开 Wiki”，直接进入当前应用的 Wiki Web 界面；原“管理知识 → Wiki”入口保留。非本地库不显示，不创建匿名站点、新窗口或公开 URL，不新增权限或模型调用。

目录采用原生列表/按钮组成的两层导航：页面 → 当前页面的章节（按修订中的 sections 顺序）。点击页面读取正文并展开章节，再次点击当前页面可收起/展开章节而不重复读取；点击章节滚动并把焦点移至对应标题。标题同名也依赖稳定 sectionId 定位。其他页面章节按需读取，不预取全库，不将互链当父子页关系，也不生成虚构分类。当前不支持人工拖拽/多级父子页面。

已发布和草稿仍分开，搜索仍只查已发布页。目录按原 API 分页加载，“更多页面”不得清空正在阅读的正文；错误/空态沿用既有提示。窄屏目录在正文上方，标题换行、键盘按钮操作、当前页面/章节可辨识。无 API/数据库变更；撤掉入口与导航展示即可回退，不改页面数据。

## 信息结构

沿用知识库详情，增加“原始资料 / Wiki”视图，不新增一级导航。Wiki 桌面为左侧分类/页面目录、中央正文、默认折叠的“来源与关联”；窄屏将目录变为抽屉，来源移到正文下方。首期不展示图谱、节点数量或数据库术语。

首页展示已发布主题与最近更新，不把所有原始文档都说成已整理。主操作“生成 Wiki”：选择资料 → 显示数量、预计调用预算、模型与数据发送提示 → 明确开始。无模型仅影响生成，不禁用浏览和搜索。失败/跳过显示可操作原因，不让用户理解内部任务枚举。

生成后显示“草稿已生成，待核对发布”，可打开差异、来源和问题列表。发布是明确动作；未保存编辑离开时提示。手动改动生成新修订，不被下一次生成直接覆盖。来源不足时发布按钮禁用且 API 同样拒绝。

## 阅读与搜索

正文内部链接打开同库页面，浏览器前进/后退保留知识库、pageId 与章节定位；点击来源展开对应证据，再按权限查看原文件。定位只标现有 normalized-text 片段，不虚构页码。相关页和“引用此页”按需加载，不预取全库正文。

Wiki 内只有一个搜索框；标题/别名优先命中，结果一页一项，显示标题和片段。默认不展示 BM25/RRF 数字，不把无语义模型提示成故障。清空搜索回目录，搜索无结果提供“查看原始资料”。原始资料搜索保持现有行为，不暗中开启统一搜索。

## 必须覆盖的状态

| 状态 | 用户反馈 |
| --- | --- |
| 未创建 Wiki | 说明用途及“选择资料生成”，原始资料入口可用 |
| 没有可用版本证据 | 指出需要重新入库的文档，不伪造来源 |
| 生成中/取消中 | 阶段、已处理/总块数、取消；完成比例不是模型质量 |
| 部分完成/重启中断 | 已保留草稿、未处理数、显式继续/重新生成 |
| 草稿/待发布 | 独立标签，仅管理者查看，不混入正常搜索 |
| 来源更新 | “来源已更新，本文待核对”，可查看旧引用、生成更新草稿 |
| 来源不可用/无权限 | 无正文/摘要泄露，统一不可访问说明 |
| 链接失效/归档 | 不自动跳转同名页面，显示目标不可用 |
| 并发编辑冲突 | 保留编辑内容，提示重新加载比较，不自动覆盖 |
| 索引异常 | 明确检索暂不可用，不显示“没有相关知识” |

切库、切页、输入改变、卸载使旧请求失效；迟到成功、错误、finally 不改变当前视图。重复点击生成/发布由 UI 防抖和服务端幂等双重保护。可键盘导航、焦点明确，状态不只用颜色表达；恶意 Markdown、URL 和图片不得触发脚本/隐式联网。

## WK-T12：生成进度反馈（2026-10-19）

WK-P01：生成状态使用独立高对比度进度卡，显示真实文本块处理比例、保存页数、任务等待时间及状态说明。百分比只表示文本块处理，不代表模型 token 或剩余时间；排队/首批等待使用活动指示，不伪造进度。完成、部分成功、失败、取消及中断均停止活动动画；取消请求不冒充已取消。轮询错误提示暂停更新并保留既有重试入口。支持窄屏、屏幕阅读器及减少动画偏好。

WK-P-T01：浏览器回归验证运行中进度条、等待说明及完成状态。类型检查与构建；不更改 API、存储、权限和模型调用。回滚仅恢复 UI，无数据迁移。实现与实际验证结果记录在 status.md。

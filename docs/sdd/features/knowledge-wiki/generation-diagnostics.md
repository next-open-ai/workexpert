# WK-T17：生成阶段与显式重新生成

状态：已验证（工程回归）；版本：0.1；日期：2026-10-21。实际证据与未验证项见 [status](status.md)。

## 需求 WK-D17

改善生成过程可解释性及失败后的操作，不新增设置或权限界面，不接统一 Reranker。断点续算、候选持久化、跨任务主题合并留待后续，不能将重新生成称为恢复检查点。

## 契约与实现

WikiGenerationJob 增加可选 progress：phase 为 queued/generate/merge/save/link/done，batchIndex 为 0～8（0 表示尚未开始），batchCount 为 1～8。orchestrator 在实际阶段开始前保存；失败、取消、中断保留最后阶段。不保存供应商异常正文、模型配置、原文或密钥。processedChunks 仍只表示通过校验的文本块；100% 文本处理不等于任务成功。

沿用 SQLite v6 JSON payload，无表迁移；新读写器接受无 progress 的旧任务，旧任务 UI 不猜测阶段。旧严格读写器不接受新增字段，因此回滚 UI/执行代码时保留更新后的 contracts 读写兼容层，不降级或删除数据库。

UI 保留进度卡，增加一行当前阶段与批次；技术详情默认折叠，仅含任务 ID、更新时间及安全错误码。失败/部分成功/取消/中断时提供“重新生成”按钮：仅打开原资料预选，过滤已不存在资料并提示；清除旧请求幂等键。再次点击“开始生成”才调用当前模型，以最新资料创建新任务、新草稿，不覆盖已有页，不自动重试。资料列表读取失败清空选择，不允许误用旧列表提交。

## 验收 WK-D17-T

- orchestrator：逐批/合并/保存/链接/完成阶段与实际操作一致，失败保留阶段，取消不多调用，旧任务可读。
- 浏览器：真实 API 返回阶段；默认折叠详情；失败后重新生成预选原资料，点击入口不调用模型，再确认才生成；既有发布与浏览闭环回归。
- contracts/orchestrator/API/renderer 构建和相关测试，Wiki 浏览器回归、并发回归、手册生成和文档构建。真实模型质量、安装态及断点续算不在本次验证范围。

# Wiki 小批量功能闭环（WK-T04a / WK-T06a）

单批输入限制现由 [0.7 有界分批](batching.md) 扩展，下文 0.5/0.6 记录此前子阶段范围；编辑与发布语义不变。

状态：实施中；版本：0.6；日期：2026-10-16。关联：[契约](contracts.md)、[状态](status.md)、[ADR](../../../architecture/adr/0006-evidence-driven-wiki.md)。

用户要求优先功能闭环，暂停 WK-T09b 权限扩展；保留现有库级入口和来源校验。

## 本次范围与契约

- WK-T04a 是 T04 的有界子集：一次 1～5 份本地版本化资料，最多 100 个子块、48,000 字符（序列化快照上限 128,000 字符）。完整读取全部有效子块及标题，不用 TopK、不静默截断；超限拒绝并要求分批。一次逻辑生成调用，120 秒、最多 8,000 输出 token，最多 8 页；编排层无自动重试、无自动发布。沿用 Pi 的供应商 SDK 网络重试，不能承诺仅一次 HTTP 请求或一次计费；所有传输受同一超时/取消信号限制。长文逐块提取/合并仍归 T04。
- 模型只输出主题、章节、来源块 ID 和同批页面链接。服务端构造证据、哈希、定位和页面 ID；未知引用、遗漏输入块、非法输出整体拒绝。覆盖率仅表示引用覆盖，不代表语义正确，必须核对发布。
- POST `generation-jobs`：documentIds、model（沿用既有临时模型配置，绝不持久化密钥）、idempotencyKey；返回 202 job。GET `generation-jobs` 返回最近五项，GET `generation-jobs/:jobId` 和 POST 同路径 `/cancel`（空对象）查询/取消。GET `pages/:pageId/sources?revisionId=...` 返回已授权修订的真实块文本和原文件名，沿用页面实时校验；不返回路径。错误沿用 `{code,message}`。
- orchestrator 负责 queued → running → completed/partial/failed/cancelled/interrupted；复用全局 dispatcher 的普通优先级容量。每库只允许一个活动生成。SQLite v6 新增作用域隔离任务元数据及检查点，保存输入版本/块数、草稿 ID，不保存模型密钥或原文 prompt。同 key 重试不再次调用模型；重启识别为 interrupted，保留已保存草稿，不自动恢复计费。
- 保存先创建本批全部草稿，再提交真实 pageId 链接；逐页检查来源、CAS 和幂等，失败保留已保存页。不更新同名旧页面或人工修订。重新生成是新批次，界面明确提示可能重复。
- 首次显式生成前备份并验证 SQLite 一致快照，再迁移 v4/v5→v6；GET 仍不初始化。普通证据访问兼容 v6。回滚关闭入口，保留 v6 数据，不能用旧版本降级打开。
- WK-T06a：知识库详情内 Wiki 页签；选择资料、明确模型发送提示、生成进度、取消、草稿/已发布目录、核对发布、标题/别名/关键词搜索、同库链接与原文下载。安全文本渲染，不执行模型 HTML/链接或加载外部图片。浏览不依赖模型。编辑/文本对照由下述 T06b 接续，完整历史导航/恢复仍归 T06。

## WK-T06b：编辑与版本对照（0.6）

关联 WK-04/07/08/12。复用 PUT draft、GET revisionId 和现有 CAS，不新增数据库、迁移或权限。用户可编辑标题、逐行别名、摘要和现有章节标题/正文；章节 ID、原文引用、链接保持不变，不支持新增/删除章节或替换来源。重建正文时重新计算 UTF-16 区间，保留每节引用，不让位置随字数变动失真。

编辑已发布页时如有草稿，先打开现有草稿，不从已发布内容覆盖它。编辑弹窗使用原生模态焦点隔离；未保存离开/刷新提示，保存期间禁止再次提交或关闭。保存新不可变修订但不发布，之后重新核对才能发布。校验失败/网络失败/CAS冲突保留本地输入，不自动重试或合并；同内容重试复用幂等键，改变内容生成新键。

版本对照默认折叠：有已发布修订时读取捕获的 publishedRevisionId；首次草稿与打开编辑时版本比较。按标题/别名/摘要及章节标记变化并并列显示，明确不是逐字符差异；只用文本渲染。引用只读展开核对。冲突后可查看最新服务器版本作比较，但不自动提升保存基线，避免把旧编辑强行覆盖新版本。

WK-U03 浏览器：草稿编辑→保存→未发布不改变搜索→再次核对发布→新词召回、旧修订不变；改字数/emoji后来源与区间仍匹配；已有草稿入口、未保存离开取消、冲突保留输入/最新版本查看、窄屏和HTML安全。WK-A05 API 断言发布前后隔离/历史/CAS/幂等。手册同步新增步骤。回退仅移除编辑入口，已保存修订继续可读；无数据降级。
